# Java Tutorial — Class 11
## IntelliJ IDEA Customization

IntelliJ IDEA-এর **Theme, Font এবং Icons** পরিবর্তন করে IDE-কে নিজের পছন্দ অনুযায়ী সাজানো যায়।

## 1. Settings Open করা

IntelliJ IDEA থেকে:

**File → Settings**

এখানে IDE-এর বিভিন্ন customization option পাওয়া যায়।

---

## 2. IDE Theme Change

যান:

**File → Settings → Appearance & Behavior → Appearance**

এখান থেকে পছন্দের **Theme** নির্বাচন করুন।

তারপর:

**Apply → OK**

---

## 3. Material Theme UI Plugin

IDE-কে আরও professional/customized করতে **Material Theme UI** plugin ব্যবহার করা যায়।

### Install করার নিয়ম

1. **File → Settings**
2. **Plugins** নির্বাচন করুন
3. **Marketplace**-এ যান
4. Search করুন: `Material Theme UI`
5. **Install** করুন

---

## 4. Atom Material Icons

IDE-এর বিভিন্ন icon পরিবর্তনের জন্য:

**Plugins → Marketplace → Search: `Atom Material Icons`**

তারপর **Install** করুন।

Plugin install করার পর প্রয়োজন হলে **Restart IDE** করুন।

---

## 5. Theme নির্বাচন

Plugin install করার পর:

**File → Settings → Appearance & Behavior → Appearance**

এখান থেকে নতুন Theme নির্বাচন করে:

**Apply**

করুন।

---

## 6. Font Change

IDE-এর font এবং font size পরিবর্তন করা যায়:

**Settings → Appearance**

এখান থেকে প্রয়োজন অনুযায়ী:

- Font
- Font Size

পরিবর্তন করুন।

---

## 7. Icons Change

**Appearance** অথবা **Atom Material Icons Settings** থেকে বিভিন্ন IDE icon customize করা যায়।

---

## Quick Revision

```text
Settings       → File → Settings
Theme          → Appearance
Plugin         → Plugins → Marketplace
Material Theme → Material Theme UI
Icons          → Atom Material Icons
Font           → Appearance → Font
```

## Practice Task

নিজের IntelliJ IDEA-তে:

1. একটি নতুন Theme নির্বাচন করুন।
2. Font Size পরিবর্তন করুন।
3. Material Theme UI install করুন।
4. Atom Material Icons install করুন।
5. IDE Restart করে নতুন appearance পরীক্ষা করুন।
